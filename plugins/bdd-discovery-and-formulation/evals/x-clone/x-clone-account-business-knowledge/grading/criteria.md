# X のクローンのアカウントに固有の条件

この条件は、x-clone の viewpoints.md のうち、アカウントの業務に当たる観点を判断の型に書き直したものである。

### account-identity-boundary

要件は、利用者の登録とログインを外部の本人確認に頼って定めている。split.md は、外部の本人確認を検証の外にある持ち主としている。

PASS：本人確認の仕組み（外部の認証の手順、トークン、署名の検証など）を業務の決まりに入れず、外部が持つことを範囲の外として示している。そのうえで、要件が外部の識別と利用者の対応について定めている登録の決まり（誰がいくつ利用者を持てるか、同じ外部の識別から何が生まれないか）を、仕組みと切り離して業務の決まりとして書いている。

FAIL：本人確認の仕組みが業務の決まりや BDD の条件に入っている。または、要件が定めている登録の決まりが、仕組みと一緒に外されて消えている。

### account-scope

要件は、初期リリースで扱うアカウントの行いと、扱わない行いを書いている。

PASS：要件が扱わないとしたアカウントの行い（登録の後の変更や、やめることなど）を、対象外として資料に書いている。扱う行いについては、要件の文から一つに決まる決まりを、仮説にも grill の問いにもせず、要件を根拠に書いている。

FAIL：要件が扱わないとした行いに BDD や決まりを作っている。または、扱わないことが資料から読み取れない。または、要件の文から決まる決まりを仮説や問いにしている。
