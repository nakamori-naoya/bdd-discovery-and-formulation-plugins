# 論理データモデル定式化の実行指示

この入口は、既存のBDD付きRDB論理データモデルを対応する業務知識と突き合わせ、境界値、反例、順序、重複、同時実行、権限内の悪用、時間、遡及、失敗時保証から反証して、確認済みの発見を同じ正式な定義へ戻す。

## 問いの選び方

`grill`へ渡すのは、調べても分からず、答えによって残す事実、履歴、業務制約、BDD、論理テーブル・列が変わる問いだけである。対象RDB、版、Read、index、物理型、分離レベル、配置、運用だけを変える問いは論理定式化へ混ぜず、物理設計への引き渡し事項にする。

各問いは、既存論理資料のどの主張を何で反証するか、推奨する解釈と根拠を持つ。返った未決は推奨を添えて未決へ書き、止まるか進むかはSKILL.mdの停止条件に従う。

## 反証の順序

1. 作成・更新・削除と、取消・失効・訂正・物理削除の区別
2. 値の境界、単位、精度、多重度
3. 状態遷移、順序逆転、重複、再試行。再試行では、同じ入力で必ず失敗する要求が失敗の事実で打ち切られ、候補から外れるかを当てる
4. 同時実行で許してはいけない業務結果
5. 権限内の悪用、時刻、規則変更の遡及
6. 失敗時に残す事実と説明責任

反証で新しい中心概念の探索が必要だと判明した場合は、この入口で推測して埋めず、初回発見が必要な理由を返す。反証対象はあるが境界の解釈が揺れる場合は、SKILL.mdの停止条件に従う。
