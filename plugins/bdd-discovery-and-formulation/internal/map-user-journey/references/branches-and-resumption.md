# 分岐・中断・再開

分岐は、目的達成に関係する選択または状態差により、後続の場面が変わるときに書く。実装上の条件分岐は書かない。

分岐ごとに次を明らかにする。

1. どの場面から分かれるか
2. 何の違いで分かれるか
3. どの状態へ進むか
4. 元の目的達成へ合流するか、別の終了になるか

中断できる場合は、中断時に成立している状態と、再開時に必要な状態を書く。再開後に最初からやり直すのか、途中から続けるのかが根拠から決まらなければ未決にする。

役割が移る場合は、誰から誰へ何の状態が渡り、受け手が何を観測できれば次へ進めるかを書く。組織名やシステム名だけを矢印でつないで済ませない。
