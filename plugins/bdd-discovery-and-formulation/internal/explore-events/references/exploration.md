# 洗い出しの進め方

**探索であって、聞き取りではない。** 相手が語れることだけ書き留めると、語られない部分（例外・時間・後始末）が丸ごと落ちる。

## 順番

1. **幹を1本通す。** 業務が始まってから終わるまでを、いちばん普通の流れで並べる。ここでは例外を扱わない
2. **枝を足す。** 幹の各点で「うまくいかなかったとき何が起きるか」を問い、別の事実として並べる
3. **誰も操作しない時間を探す。** 期限、放置、自動締め。ここは相手から出てこない
4. **外から来るものを探す。** 相手先のキャンセル、入金、通知。こちらが拒めない事実
5. **後始末を探す。** 取消・訂正・払戻・再発行。**多くの業務知識はここに埋まっている**

**幹が通る前に枝へ行かない。** 例外から入ると、何が普通なのかが最後まで分からない。

## 問い方

**1つの事実について1つだけ問う。** まとめて聞くと、答えやすいものだけが返る。

| 状況 | 問い |
|---|---|
| 事実が出た | 「これが起きた後、次に何が起きますか」 |
| 幹が通った | 「これが起きないことはありますか。そのとき何が起きますか」 |
| 引き金が曖昧 | 「誰かがやるのですか、時間が来たら起きるのですか」 |
| 結果が曖昧 | 「これが起きた後、何がどう変わっているのですか」 |
| 取消が出た | 「取り消した後、元に戻るのですか。戻らないものは何ですか」 |
| 語が揺れた | 「その言い方と、さっきの言い方は同じものですか」 |

**調べれば分かることを問わない。** 既存の資料・記録に書いてあるものは先に読み、食い違いだけを問う。

## 拾ってはいけないもの

**仕組みの都合で起きることは、業務の事実ではない。** 次が出てきたら、その裏にある業務の事実へ言い換える。

| 出てきたもの | 業務の事実へ言い換える |
|---|---|
| 画面・ボタン・入力欄 | その操作で業務上何が起きたか |
| 保存・更新・削除 | 業務上どういう状態になったか |
| 通知が飛んだ | 誰が何を知る必要があったか |
| バッチが回った | 時間が来て何が確定したか |

**言い換えられないものは、業務の事実ではない。** 台帳へ入れず、そう判断したことだけ伝える。

## 止めるとき

- 新しい事実が出ず、既出の言い換えばかりになった
- 未確認が積み上がり、確かめられる人がその場に居ない
- 1つの題材で事実が30件を超えた（題材が大きすぎる）

**止めたら、何が残っているかを必ず言う。** 「洗い出せた」と「聞ける範囲を聞き切った」は違う。
