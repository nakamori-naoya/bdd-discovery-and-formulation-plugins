# visual-guidance

**何を、どの図で伝えるかを決める。** 文章の規律やHTML/SVGの描画方法は持たない。

## 使う

```text
/choose-visual
```

依頼・本文・素材から読み手、目的、主要な主張を取り、図の主張・図の型・図の内容と挿入位置を返す。

## 判断すること

- 図にする価値がある主要な主張はどれか
- 読み手が答えを得たい問いは何か
- 構成図、依存関係図、シーケンス図、状態遷移図などのどれが合うか
- 位置、形、線、色へ何の意味を持たせるか

## 判断しないこと

- 文章の構成・文体・強調
- HTML、SVG、Markdownなど媒体ごとの描画方法
- 資料全体で図を必須にするかという設定
- 図が無い結果を呼び出し元が許すかという判定
