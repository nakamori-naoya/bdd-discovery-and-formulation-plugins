# 詰める観点（既定）

**上から順に降りる。** 上流が決まらないうちに下流を問うても、上流が変われば全部やり直しになる。

差し替えたい場合は `.harness-plugins/grill.config.yml` の `aspects` に、同梱の観点の名前（例: `business-rules`）か、自分のファイルのパスを指す。**扱う題材によって観点は変わる**（業務システムと社内ツールでは、詰めるべき場所が違う）。

| 観点 | 何を確定させるか |
|---|---|
| **スコープ** | 何をやる／やらない。境界はどこか。今回やらないものは何か |
| **主要概念・用語** | 登場する概念とその定義。同義語・紛らわしい語をどちらに寄せるか |
| **不変条件** | 常に真でなければならない条件。破れたらどう拒むか |
| **状態遷移** | 取りうる状態と遷移。許す遷移／禁じる遷移。終端はどこか |
| **権限** | 誰がその操作を行えるか。役割ごとの可否 |
| **境界値** | 0・最大・最小・空・重複・上限超過。それぞれの期待挙動 |
| **例外・拒否** | 失敗する場合と、なぜ拒むかの根拠 |
| **並行・競合** | 同時に起きたら何が起きるか。順序に依存するか。冪等が要るか |
| **時間軸** | 履歴を残すか。過去・未来の日付をどう扱うか |
| **影響範囲** | 他へどう波及するか。前提にしている既存の決まりは何か |

**各観点で「曖昧」または「未決」が見つかったら、1問にする。** 見つからなければ次の観点へ降りる。

**すべての観点を必ず問うのではない。** 題材に関係のない観点は飛ばす。飛ばしたことは決定ログに残さない（決めていないので）。
