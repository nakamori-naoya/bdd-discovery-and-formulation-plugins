# grill の問い詰めワークフロー

## 先に調べる

問いを立てる前に、手元で分かることを潰す。コード・既存文書・履歴を確認し、調べて分かったら「この前提でいく」と宣言して進む。黙って前提にしない。

## 1問ずつ詰める

観点を上から降りる。曖昧・未決が見つかったら1問にする。推奨回答と理由を必ず添え、相手が確認か修正だけで進める状態にする。

答えを待ってから次へ進む。前の答えで次の問いが変わるため、一度に大量の問いを出さない。

## 決めたことを記録する

```bash
python3 "${PLUGIN_ROOT}/scripts/decision.py" add --config "$CFG_FILE" \
  --topic "<題材>" --aspect "<観点>" --what "<決めたこと>" --why "<理由>"
```

後でまとめて書かない。その場の理由は時間が経つと再現できない。理由が空だと書けない。

決められないものは `--status open` で未決として残す。取り下げたものは `--status dropped` で、なぜ取り下げたかを理由に書く。

## 合意を要約する

```bash
python3 "${PLUGIN_ROOT}/scripts/decision.py" render --config "$CFG_FILE" --topic "<題材>"
```

決定・未決・取り下げを並べて見せる。未決が残っていることを隠さない。
