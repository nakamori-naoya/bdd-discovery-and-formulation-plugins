# 素材の役

**役は名前だけの契約である。** どの素材をどの役へ当てるかは書く工程が決め、その役をどの節へ置くかは型が決める。**互いを見ない。**

| 役 | 何を指すか | 落ちていると何が起きるか |
|---|---|---|
| **業務イベント** | 業務の側で起きた事実 | 決まりだけが並び、いつ効くのかが読めない |
| **担い手** | その行いを誰が行うか | 権限の話が書けず、誰でもできると読まれる |
| **常に守られること** | 状態や操作によらず破ってはならない決まり | 例外の説明が積み上がり、原則が見えなくなる |
| **移り変わり** | 取りうる状態と、移れる先・移れない理由 | 終わったはずのものへ操作できてしまう |
| **業務ルール** | 成立条件・境界値・拒否条件 | 具体例だけが残り、一般の決まりが読み取れない |
| **拒む理由** | 業務として拒む理由と、その根拠 | 拒否が理不尽に見え、現場で回避される |
| **未決** | まだ決まっていない論点と、何が分かれば決まるか | 空欄が「決まっている」と読まれ、勝手な解釈で実装される |

## 確からしさは役ではない

**役と直交する。** どの役の素材にも、確認済み・仮置き・未確認がありうる。

**束ねるときに落とさない。** 確からしさを落とすと、確かめていないことまで確定として本文へ入る。**これが業務の正本でいちばん起きやすい事故である。**

## 実装の関心は役を持たない

画面・保存・境界のやりとり・手順の組み立ては、どの役にも当たらない。**当てる先が無いものは、正本へ入れない。**
