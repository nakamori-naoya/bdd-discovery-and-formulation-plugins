# Journey の働きかけから結果を反証する

## 決定

Journey の最終確認では、置いた各働きかけについて、入力が定める観測結果を当てて反証する。その結果によって主たるユーザーの次の行動や目的達成が変わるなら、場面・接続・完了条件の抜けを直す。目的に関係しない業務判断まで列挙しない。

## 理由

開始から完了への主経路だけを確認すると、途中の働きかけが返す別の結果によって経路が止まる、続く、未達のまま残る場合を見落とす。既に置いた場面から入力へ戻れば、Journey に必要な結果を見つけつつ、業務知識全体の網羅へ広げずに済む。

## 確かめる境界

入力が定める別の結果で次の行動が変わる例では、その結果から目的へ至る接続を確認する。入力にある判断でも目的への経路を変えない例は場面に増やさない。入力が結果を定めず、答えによって場面の結論が変わる例は、既存の停止条件に従う。
