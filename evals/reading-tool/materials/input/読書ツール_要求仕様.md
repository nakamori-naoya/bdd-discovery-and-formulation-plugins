# 読書ツール要求仕様（栞・マーカー）

読み手が本文に栞をはさみ、マーカーを引くための機能の要求をまとめる。実装は [reader_tools/](<./reader_tools/>) と [serve.py](<./serve.py>) にある。書籍ページ自体の作り方は [読書ノートHTML_実装仕様.md](<./読書ノートHTML_実装仕様.md>) が正本で、本書は扱わない。

## 目的

紙の本に付箋を貼り、線を引くのと同じことを、この本棚の書籍ページでできるようにする。操作感の基準は Kindle。読み手は本文を選んで色を選ぶだけでよく、引いた線はあとから色を変えたり消したりできる。

## 前提

- 読み手は所有者ひとり。共有・同期の要求はない
- 閲覧は Tailscale 内の端末（Mac・Android）。スマートフォンでの指の操作が主
- 書籍は今後も増える。書籍ごとに独立して栞とマーカーを持つ

## 要求

### 栞

- 選択した行に栞をはさめる
- 1冊に何ヵ所でも置ける。上限を設けない
- はさんだ行は一見して分かる
- 同じ行でもう一度操作すると外れる
- 一覧から、章をまたいで栞の位置へ移動できる

### マーカー

- 選択した範囲に線を引ける
- 色は青・黄・赤の3色
- 書籍ページが最初から持っているマーカー（黄=要点、赤=キーワード）と**線の形で区別できる**。既存は文字の下半分を塗る帯なので、読み手が引く線は別の形にする
- 引いた線を押すと、色を変えられる
- 引いた線を押すと、消せる
- 線が重なっている場合、押した1本だけが操作の対象になる

### 操作

- ツールバーは、本文を選択したときと、引いた線を押したときにだけ出る
- 何も操作していない間は出さない。次の操作を始めた時点で閉じる
- `✕` は閉じる操作。消す操作を兼ねない
- 端末標準のコピーメニューと重ならない位置に出す

## 制約

**書籍 HTML は書き換えない。** 本文は一字一句 verbatim であることをスクリプトで照合する運用（[CLAUDE.md](<./CLAUDE.md>) 参照）のため、静的ファイルに読み手の書き込みを混ぜると照合が壊れる。配信時に CSS と JS を注入し、書き込みは localStorage に持つ。

**本文の文字列を変えない。** 栞の 🔖 のような装飾で文字ノードを足すと、保存した位置がずれる。装飾は CSS の擬似要素だけで行う。

**書籍を改稿しても誤った位置に線を残さない。** 位置は行番号と文字オフセットで持つため、本文が変われば指す先がずれる。保存時に控えた本文と一致しない箇所は復元しない。

**外部に出さない。** 保存先はブラウザの localStorage に限る。外部サービスへの送信は行わない。

## 受け入れ条件

- 本文を選び色を押すと線が引かれ、再読込しても同じ位置・同じ色で戻る
- 引いた線を押すと色を変えられ、消せる。重なった線では押した1本だけが変わる
- 行を選び栞を押すとはさまり、もう一度押すと外れる。一覧から章をまたいで移動できる
- 何も選択していない状態でページ内を押しても、ツールバーが出ない
- `✕` を押してもマーカーが消えない
- 全書籍の全ページで、機能を読み込んでも本文の文字列が変化しない

## 対象外

- 引用文の抜き出し、メモの添付、検索
- 端末間の同期、バックアップ、書き出し
- 書籍ページに最初から入っているマーカー（黄・赤）の編集。あれは読解の成果物であり、読み手が引く線とは別物として扱う
